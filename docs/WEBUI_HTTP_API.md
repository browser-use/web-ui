# Browser-Use WebUI HTTP API (port 7788)

The app on **port 7788** is a **Gradio** application. It does not expose a custom REST API with fixed paths like `/api/goto`. Instead, Gradio auto-exposes every **event listener** (e.g. button clicks, form submits) as callable endpoints.

## What is “:7788/api/goto”?

- **`:7788`** — the Gradio app (browser-use-webui).
- **`/api/...`** or **`/call/...`** — Gradio’s internal API. The exact path depends on the Gradio version:
  - **Gradio 4.x**: endpoints are under **`/call/<api_name>`** (e.g. `/call/predict`, `/call/submit_wrapper`).
  - **Gradio 5.x** (this app uses 5.x): endpoints are under **`/gradio_api/call/<api_name>`** (e.g. `/gradio_api/call/goto`). The prefix `/gradio_api` is required; plain `/call/goto` returns 404.

The app exposes **stable** `api_name`s for browser control: **goto**, **get_url**, **get_title**, **screenshot** (see table below). Call them via **`/gradio_api/call/<api_name>`** or with `gradio_client`. So:

- **`/api/goto`** is either:
  - An endpoint name **auto-generated by Gradio** from one of the app’s events (names can be hashed or derived from function names), or
  - From another app/service you had in mind.

To see the full list of endpoints for your run, use “Discover endpoints” below.

## Discover endpoints

1. **In the browser**  
   Open the WebUI (e.g. `http://127.0.0.1:7788`), scroll to the **footer** and click **“Use via API”** (or “View API”). There you get:
   - List of all API endpoints (names and parameters)
   - Example requests (e.g. curl, Python client)

2. **OpenAPI (machine-readable)**  
   Gradio serves an OpenAPI spec at:
   ```text
   http://127.0.0.1:7788/gradio_api/openapi.json
   ```
   From it you get all paths, methods, and parameters.

3. **Example: list info from OpenAPI**  
   ```bash
   curl -s http://127.0.0.1:7788/gradio_api/openapi.json | jq '.paths | keys'
   ```

## How to call an endpoint (Gradio pattern)

Gradio uses a **two-step** pattern:

1. **POST** to start the job (returns `event_id`):
   ```bash
   curl -X POST "http://127.0.0.1:7788/gradio_api/call/ENDPOINT_NAME" \
     -H "Content-Type: application/json" \
     -d '{"data": [ ... inputs in order ... ], "session_hash": "optional-session-id"}'
   ```
   Response example: `{"event_id": "..."}`.

2. **GET** to fetch the result (streaming or final):
   ```bash
   curl -N "http://127.0.0.1:7788/gradio_api/call/ENDPOINT_NAME/EVENT_ID"
   ```

Replace `ENDPOINT_NAME` with the exact name from the “Use via API” page or from `openapi.json` (e.g. it might be `submit_wrapper` or a hash, not necessarily `goto`).

## Python client (recommended)

Using `gradio_client` you don’t need to handle `event_id` or paths by hand:

```bash
pip install gradio_client
```

```python
from gradio_client import Client

client = Client("http://127.0.0.1:7788")

# List all API endpoints
print(client.view_api())

# Call an endpoint by name (name from view_api())
# Example: if there is an endpoint that takes (task, ...) and returns (messages, ...)
# result = client.predict(task="Open google.com", api_name="/submit_wrapper")
```

`view_api()` prints the exact endpoint names and their input/output types.

## How to open a URL in the browser

1. **Ensure the browser is running**  
   Either:
   - **Startup browser**: set `LAUNCH_BROWSER_AT_STARTUP=true` and `BROWSER_CDP=http://127.0.0.1:9222` in the container; the browser starts at boot and the WebUI connects to it, or  
   - **On first agent run**: call **run_agent** with any task (e.g. "Open google.com"); that launches the browser and creates a context.

2. **Call goto**  
   Use Gradio API with **api_name `"goto"`** and one argument: the URL string.
   - **gradio_client**: `client.predict("https://example.com", api_name="goto")`  
   - **HTTP (verified with Gradio 5)**:
     ```bash
     EVENT=$(curl -s -X POST "http://127.0.0.1:7788/gradio_api/call/goto" -H "Content-Type: application/json" -d '{"data":["https://example.com"]}' | jq -r '.event_id')
     curl -sN "http://127.0.0.1:7788/gradio_api/call/goto/$EVENT"
     ```
     Response body includes `event: complete` and `data: ["OK: navigated to https://example.com"]`.

If the browser is not open, **goto** returns: `"Error: Browser not open. Run an agent task first (run_agent) so the browser is started."`

## Browser and agent control endpoints (stable names)

### Browser (direct page control)

Require the browser to be open (e.g. after at least one **run_agent** or with startup browser + **BROWSER_CDP**).

| api_name | Purpose | Inputs |
|----------|--------|--------|
| **goto** | Navigate current tab to URL | One string: `["https://example.com"]`. URL without scheme is prefixed with `https://`. |
| **get_url** | Return current page URL | None (`data: []`). |
| **get_title** | Return current page title | None. |
| **screenshot** | Return screenshot (base64) of current page | None. |

### Agent and session

| api_name | Purpose | Inputs |
|----------|--------|--------|
| **run_agent** | Start an agent task (task text + all UI settings). | Full component state; order from OpenAPI or `view_api()`. |
| **stop_agent** | Stop the running agent. | None. |
| **pause_resume_agent** | Pause or resume the agent. | None. |
| **clear_agent** | Clear chat and Run Agent tab state. | None. |

Use path: **`/gradio_api/call/<api_name>`** (e.g. `POST /gradio_api/call/goto` with `{"data":["https://example.com"]}`, or `POST /gradio_api/call/stop_agent` with `{"data":[]}`). Then `GET /gradio_api/call/<api_name>/<event_id>` to fetch the result.
